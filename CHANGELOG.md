# Changelog

## v0.1.0 — First Public Preview

Initial public-preview foundation for the Open Binary Gibbs Energy Library.

### Added

- Initial repository structure and naming conventions.
- Design Philosophy and Project Notebook.
- Initial JSON information model separating system metadata from phase thermodynamic models.
- Explicit phase identifiers and human-facing display names.
- Explicit composition-coordinate metadata to allow future models beyond simple mole fractions.
- Structured temperature-dependence terms rather than executable equation strings.
- Generated TeX/PDF model representations as derived artifacts of canonical JSON data.
- Initial provenance and verification conventions.
- Separation of OBGEL from the related Phase Diagram Tool.

### Not yet included

- The first curated thermodynamic datasets.
- Final licensing decisions for code, data, and bibliography.
- Additional language readers beyond the initial Wolfram Language direction.
- Automated continuous-integration validation.
- Publication and dissemination materials.

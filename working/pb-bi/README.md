# Open Binary Gibbs Energy Library — Pb-Bi

This package contains the source-audited Pb-Bi thermodynamic model based on Yoon and Lee (1998).

Primary source: S. W. Yoon and H. M. Lee, *Calphad* 22 (1998) 167–178, DOI 10.1016/S0364-5916(98)00022-4.

The package includes the four Pb-Bi phases represented in the current OBGEL candidate: liquid, FCC A1, HCP A3 (epsilon Pb), and rhombohedral A7 (Bi-rich).

The data package also includes the development observations and a provenance record documenting the source audit and the critical correction to the Bi unary reference contributions in FCC and HCP.

# Ag-Pt validated source model

Karakaya and Thompson (1987), original liquid/FCC functions. Validated implementation with source qualifications; 1238.15–2100 K, composition xPt.

Load [system.json](system.json) through the binary reader, or run [user-reader-check.wl](user-reader-check.wl) after loading the reader. One FCC function provides both solid contacts.

See [source-audit.md](source-audit.md) and [validation-diagnostics.json](validation-diagnostics.json). The maximum Table 6 mismatch of 0.291 atomic-percent Pt remains documented. Low-temperature phases are deferred; no canonical SGTE unary substitution was made.

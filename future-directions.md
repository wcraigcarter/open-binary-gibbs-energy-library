# Future Directions

This file records ideas that are intentionally deferred while the first public-preview foundation is established. It is not a commitment to implement every item.

## Potential future work

- Add a first curated batch of verified thermodynamic systems.
- Establish a formal contribution and curator-review workflow.
- Resolve separate licensing for source code, curated thermodynamic data, and bibliographic material.
- Add readers or reference implementations for Python, Julia, MATLAB, or other languages.
- Add automated schema and dataset validation in continuous integration.
- Build a generated MyST/GitHub Pages documentation site.
- Establish a persistent scholarly citation mechanism such as a DOI.
- Prepare a software/data publication or arXiv preprint after the collection has sufficient scientific substance.
- Extend the information model to additional phase-model classes as justified by real examples.

The project should resist adding infrastructure merely because it is technically possible. New capabilities should solve a demonstrated need or substantially improve scientific reproducibility or pedagogy.

# Contributing to the Open Binary Gibbs Energy Library

The project is currently in its initial design and curation stage. The contribution process will be formalized before the repository is opened for general contributions.

For now, the most useful contributions are:

- suggestions for well-documented binary alloy assessments that are especially useful for teaching;
- corrections to bibliographic information or documented validity ranges;
- reports of transcription or implementation errors;
- suggestions for improvements to the data schema and reference readers.

For a proposed thermodynamic model, please preserve the distinction between the original published source and the machine-readable representation created for this project. In particular, do not submit proprietary database files in place of an open, traceable source.

A formal contribution checklist and review workflow will be added before the public release.
